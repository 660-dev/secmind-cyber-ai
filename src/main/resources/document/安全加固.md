# 网络安全知识库 - 安全加固篇

#### 什么是网络安全等级保护，基本要求有哪些？
网络安全等级保护（等保）是我国网络安全领域的基本制度，要求运营者根据信息系统的重要程度和受破坏后的危害，将其划分为五个安全保护等级，并按对应等级落实安全建设和管理。常见的非涉密企业系统多为二级或三级。等保 2.0 从技术和管理两个层面提出要求，技术层面包括安全物理环境、安全通信网络、安全区域边界、安全计算环境和安全管理中心；管理层面包括安全管理制度、管理机构、管理人员、建设管理和运维管理。落地流程一般为定级、备案、建设整改、等级测评和监督检查。企业应结合等级要求，在身份鉴别、访问控制、安全审计、入侵防范、数据备份和应急演练等方面形成闭环。

#### 如何对操作系统进行安全基线加固？
基线加固是按标准配置消除系统默认风险。账号与口令方面，应重命名或禁用默认管理员账号、删除无用账号，设置强口令策略（长度、复杂度、有效期）和登录失败锁定，限制远程登录权限。访问控制方面，遵循最小权限原则分配权限，关闭不必要的服务和端口，及时安装安全补丁。远程管理方面，Linux 禁用 root 直接登录、改用密钥登录并限制 SSH，Windows 限制远程桌面来源。审计方面，开启登录、权限变更和关键操作的日志记录并集中收集。此外还应配置主机防火墙、安装防病毒或 EDR、设置屏幕锁定和超时退出，并通过基线核查工具定期检查配置漂移。

#### 如何安全地管理账号、权限和口令？
账号权限管理的核心是最小权限和职责分离。应为每个用户分配独立实名账号，避免共享账号，按角色基于最小必要授权，采用基于角色的访问控制（RBAC），并定期复核权限、及时回收离职或转岗人员权限。口令方面，强制使用足够长度和复杂度的口令，避免弱口令和重复使用，推荐使用密码管理器生成和保存，关键系统启用多因素认证。对管理员等高权限账号应重点保护，限制使用范围、启用多因素认证并记录操作审计。还应通过堡垒机集中运维、统一身份认证和单点登录，并对特权账号的使用进行审批和全程录像审计，降低凭证泄露和滥用风险。

#### 网络边界防护有哪些常用手段？
网络边界防护的目标是在不同信任区域之间实施受控的访问和监测。防火墙是基础，通过访问控制策略按源目地址、端口和协议做最小化放行，默认拒绝非必要流量。入侵检测与防御系统（IDS/IPS）对边界流量进行特征和行为分析，识别并阻断攻击。Web 应用防火墙（WAF）专门防护针对 Web 应用的注入、跨站等攻击。还可通过网络分区和隔离（DMZ、VLAN、零信任分段）限制横向移动，部署 VPN 或零信任网关保障远程接入，使用上网行为管理和反垃圾邮件网关管控内容，并结合全流量审计、威胁情报和态势感知平台实现监测预警与联动响应。

#### 如何保障数据安全和做好备份恢复？
数据安全应覆盖数据全生命周期，包括采集、传输、存储、使用、交换和销毁。传输环节使用加密协议（如 TLS），存储环节对敏感数据加密，展示和使用时进行脱敏（如手机号、身份证号掩码），并通过访问控制和审计防止越权访问。应建立数据分类分级制度，按敏感程度采取差异化保护，遵守相关法律法规要求。备份方面推荐 3-2-1 策略：保留至少 3 份副本、使用 2 种不同介质、其中 1 份异地或离线保存，以防范勒索、误删和灾害。备份数据同样需加密保护，并定期进行恢复演练，验证备份的可用性和恢复时间目标，避免"有备份却无法恢复"。
